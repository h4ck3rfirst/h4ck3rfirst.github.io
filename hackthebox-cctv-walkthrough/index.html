HackTheBox CCTV Walkthrough

h4ck3rfirst July 16, 2026

CCTV is a medium Linux machine themed around surveillance software. The attack path teaches several important real-world skills:

  • Identifying and exploiting default credentials in open-source applications
  • Performing time-based blind SQL injection manually (not just running sqlmap and hoping)
  • Building a custom binary-search extractor when sqlmap is too slow or unreliable
  • Using SSH local port forwarding to reach internally-bound services
  • Exploiting an authenticated RCE in MotionEye to go from user → root

The machine chains four distinct vulnerabilities together — none of which are individually exotic, but together form a complete compromise path.

Key Lessons

1. Always Try Default Credentials First

Before running any exploit or brute force, check the application’s documentation for default login details. In this case admin:admin gave immediate access to ZoneMinder.

2. Time-Based SQLi Doesn’t Require sqlmap

sqlmap is great for detection, but for extraction over high-latency connections, a custom binary-search script is dramatically faster. Understanding how time-based blind SQLi works lets you write your own tools.

3. The SLEEP Multiplication Pattern

SLEEP(N * (boolean_condition))

This is more reliable than IF(condition, SLEEP(N), 0) in certain MySQL versions and query contexts. Add this to your SQLi toolkit.

4. Credential Reuse Is Rampant

The password in the ZoneMinder database worked directly for SSH. Real environments are full of this. Once you have one credential, try it everywhere.

5. Port Forward to Reach Internal Services

ss -ltup is one of the first commands to run after getting a shell. Internal-only services are often less hardened. SSH port forwarding is the cleanest way to interact with them from your attacker box.

6. Authenticated ≠ Safe

CVE-2025-60787 requires authentication — but we had credentials. “Requires auth” CVEs are often dismissed, but in a chained attack they’re critical. Never skip authenticated vulnerabilities.
