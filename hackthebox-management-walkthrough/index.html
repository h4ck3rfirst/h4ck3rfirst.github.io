HackTheBox Management Walkthrough

h4ck3rfirst September 12, 2026

Executive Summary

During the assessment of Management (10.129.50.209), an initial port scan revealed multiple exposed web, RMI, and LDAP services. An unauthenticated Remote Code Execution (RCE) vulnerability in the OpenAM instance allowed initial access as the openam user. Local enumeration uncovered plain-text and encrypted database credentials, leading to the decryption of an LDAP bind password via a custom standalone PHP script. Reusing these credentials provided SSH access as owen. Finally, local privilege escalation was achieved by exploiting a wild-card permission flag in a sudo rdiff-backup command, allowing arbitrary file read of /root and retrieving the root SSH private key.

The encrypted string is stored inside the glpi_authldaps table under the rootdn_passwd column.

Extracted encrypted LDAP bind credentials from GLPI database (glpidb.glpi_authldaps):

  • DN: cn=svc-glpi,ou=services,dc=management,dc=htb
  • Encrypted String: avrqW65aZWKzLAKWhPxZGn1eLj3yYAnwUp08mEazsJUWfI5cqbaP6vM12w0p/ykpmyO3Pw==

Using the cryptographic key located in /opt/glpi/config/glpicrypt.key, a custom PHP script utilizing Libsodium (sodium_crypto_aead_xchacha20poly1305_ietf_decrypt) was executed to decrypt the secret:

<?php
$key = file_get_contents('/opt/glpi/config/glpicrypt.key');
$encrypted_base64 = "avrqW65aZWKzLAKWhPxZGn1eLj3yYAnwUp08mEazsJUWfI5cqbaP6vM12w0p/ykpmyO3Pw==";
$ciphertext = base64_decode($encrypted_base64);

$nonce_len = SODIUM_CRYPTO_AEAD_XCHACHA20POLY1305_IETF_NPUBBYTES;
$nonce = substr($ciphertext, 0, $nonce_len);
$encrypted_data = substr($ciphertext, $nonce_len);

$decrypted = sodium_crypto_aead_xchacha20poly1305_ietf_decrypt($encrypted_data, $nonce, $nonce, $key);
echo "Decrypted Password: " . $decrypted . "\n";
?>
