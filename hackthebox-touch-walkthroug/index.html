HackTheBox Touch Walkthrough

h4ck3rfirst October 4, 2026

This walkthrough covers the analysis of a Windows target environment. The attack path demonstrates how a combination of application logic flaws, local interface escapes, exposed administrative credentials, and permissive database service permissions can allow a low-privileged account to achieve full system access.

Exectuating the shell.exe file with sys_eval .The sys_eval function acts as a programming bridge, taking whatever string text is placed inside its single quotes and passing it straight to the native Windows command execution API (system() or CreateProcess()).

C:\Users\KioskUser>C:\MySQL\bin\mysql.exe -u root -pHTB@irw4ys_DB!2026 -e "SELECT sys_eval('cmd.exe /c start /b C:\\ProgramData\\shell.exe');"
